Installed GSQL Fraud Pattern Algorithms

detect_card_not_present_fraud Pattern P1

Detects online transactions (ProductCD=W,H) with identity flag mismatches (M1, M6, M9) and high multi-address velocity (C1 > 5).

detect_card_not_present_fraud(STRING card_id, INT lookback_days)
RETURNS HeapAccum
detect_account_takeover Pattern P2

Detects transactions from first-seen devices on known cards combined with recipient email changes or large amount spikes > 2x average.

detect_account_takeover(STRING customer_id, INT lookback_days)
RETURNS ListAccum
detect_card_not_present_new_device Pattern P3

Detects card-not-present purchases originating from hardware device profiles with < 2 prior historical transactions on the card.

detect_card_not_present_new_device(STRING card_id, INT lookback_days)
RETURNS DeviceRiskAccum
detect_out_of_region_use Pattern P4

Computes 90-day geographic frequency distributions per card; flags transactions where billing region addr1 occurs with < 5% frequency.

detect_out_of_region_use(STRING card_id, STRING transaction_id)
RETURNS GeoAnomalyRecord
